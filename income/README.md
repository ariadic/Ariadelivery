# הכנסות ממשלוחים

אפליקציה אישית למעקב הכנסות: וולט ומשלוחים פרטיים, טיפים, סיכום חודשי וסיכום שנתי (נובמבר 2026 עד אוקטובר 2027).

כתובת: https://ariadic.github.io/Ariadelivery/income/

## חיבור לטבלת גוגל (פעם אחת)
הטבלה היא הגיבוי האמיתי של הנתונים. אם נתוני הדפדפן יימחקו, מחברים שוב את הכתובת והכול חוזר.

1. יוצרים טבלה חדשה ב-Google Sheets (sheets.new).
2. **Extensions > Apps Script**.
3. מוחקים את הקוד שיש ומדביקים את התוכן של `apps-script.gs` מהתיקייה הזאת.
4. אופציונלי: ב-`var KEY = ''` כותבים סיסמה. אותה סיסמה מדביקים בהגדרות האפליקציה. את הסיסמה לא מעלים ל-GitHub.
5. **Deploy > New deployment > Web app**. ב-Execute as בוחרים **Me**, וב-Who has access בוחרים **Anyone**.
6. מאשרים הרשאות (Advanced > Go to project) ומעתיקים את כתובת ה-Web app.
7. בטלפון פותחים את האפליקציה, לוחצים על גלגל השיניים, מדביקים את הכתובת ולוחצים **שמור וסנכרן**.

## הוספה למסך הבית (iPhone)
ב-Safari: כפתור השיתוף > **Add to Home Screen**.

## הערות
- הכתובת של ה-Web app היא המפתח לנתונים. לא מעלים אותה לקוד ולא משתפים אותה.
- אפשר לעבוד בלי אינטרנט: הרשומות נשמרות במכשיר ומסתנכרנות כשיש חיבור.
- בהגדרות יש גיבוי לקובץ, ייצוא ל-CSV ושחזור.
