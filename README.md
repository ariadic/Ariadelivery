# Ariadelivery – ארי משלוחים
מערכת הזמנות למשלוחים: הלקוח ממלא טופס בדפדפן, וההזמנה נשלחת בווצאפ ל-050-4848398.

- **דף ההזמנות:** https://ariadic.github.io/Ariadelivery/
- **קוד QR להדפסה:** https://ariadic.github.io/Ariadelivery/qr.html

## שינוי מחירים, ערים ושעות פעילות
בקובץ `index.html` יש בלוק `CONFIG` בתחילת הסקריפט:
- `cities` – רשימת ערים ומחיר לכל עיר (עיר שלא ברשימה = "המחיר ייקבע בשיחה")
- `urgentExtra` – תוספת למשלוח דחוף
- `hours` – שעות פעילות (מחוץ להן מוצגת הודעה ללקוח)
- `whatsapp` – המספר שאליו מגיעות ההזמנות

## לוגו
מעלים לתיקייה קובץ בשם `logo.png` והוא יופיע אוטומטית בראש הדף.

## לקוחות עם לינק אישי
ב-`CONFIG.customers` מוסיפים לקוח לפי קוד. הלינק שלו: `https://ariadic.github.io/Ariadelivery/?c=הקוד`

- `name`, `addr`, `phone`: פרטי האיסוף, ממולאים מראש
- `prices`: מחירון משלו, רשימה של `{ label, city, price }`. `label` מוצג ללקוח (למשל "קרית אתא – גבעת רם"), ו-`city` משמש לניווט בווייז
- בלי `prices` הלקוח מוגדר "מחיר לפי הסכם": לא מוצג לו מחיר, וההזמנה מסומנת כך
- `title`: כותרת משלו בראש הדף
- `sizes`: אפשרויות "מה שולחים" משלו
- `greeting: true`: מוסיף שדה "ברכה לכרטיס"
- `urgentExtra`: תוספת דחוף משלו (ברירת מחדל: 0)
- `fixedPickup: true`: פרטי האיסוף קבועים, מוצגים בלבד ואי אפשר לערוך אותם
- `pay`: אמצעי תשלום קבוע, למשל `"מזומן"`, בלי בחירה
- `hidePayer: true`: מסתיר את "מי משלם?"

## גיבוי הזמנות לטבלה ולמייל (Google Sheets)
כל הזמנה נשמרת בגיליון ונשלחת למייל **ברגע הלחיצה על הכפתור**, עוד לפני שווצאפ נפתח, כך שהזמנה לא הולכת לאיבוד גם אם שכחו ללחוץ "שלח" בווצאפ.

1. פותחים גיליון חדש: https://sheets.new ונותנים לו שם, למשל "הזמנות ארי משלוחים".
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. מוחקים את מה שכתוב שם, ומדביקים את כל התוכן של `google-apps-script.gs`. שומרים (💾).
4. למעלה בוחרים את הפונקציה **testOrder** ולוחצים **הפעלה (Run)** ← מאשרים הרשאות (Advanced ← Go to … ← Allow).
   צריכה להופיע שורת בדיקה בגיליון ולהגיע מייל.
5. **פריסה (Deploy) ← פריסה חדשה (New deployment)** ← סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   ← Deploy ← מעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).
6. מדביקים את הכתובת ב-`CONFIG.sheetUrl` בקובץ `index.html`.

בגיליון יש עמודת "סטטוס" שאפשר לעדכן ידנית (חדשה / נאסף / נמסר).

## סטטוס משלוח (נאסף / נמסר)
- **דף ניהול לארי:** https://ariadic.github.io/Ariadelivery/admin.html
  רשימת ההזמנות הפתוחות, עם ווייז וחיוג. לכל הזמנה יש כפתורים **🛵 נאסף** ו-**✅ נמסר**, וכפתור "בטל" לטעויות. הדף מתעדכן לבד כל דקה.
- **אצל הלקוח:** תחת "📋 ההזמנות שלי" ליד כל משלוח מופיע 🕓 ממתין / 🛵 בדרך / ✅ נמסר. משלוחים מימים קודמים שעוד לא נמסרו מוצגים גם הם.
- הסטטוס נשמר בעמודת "סטטוס" בטבלה בגוגל, ואפשר לשנות אותו גם ידנית בטבלה.
- **לא פנוי:**
  - **כללי:** מתג בראש דף הניהול ("סמן לא פנוי"), עם הודעה אופציונלית כמו "חוזר ב-16:00". הלקוחות רואים באתר פס אדום, ולפני שליחת הזמנה הם מתבקשים לאשר.
  - **על הזמנה:** כפתור **❌ לא פנוי** בהזמנה חדשה. הלקוח רואה ליד המשלוח "לא פנוי – צריך לתאם משלוח אחר", וההזמנה לא נספרת בסיכומים שלו.
- **הזמנות שנסגרו:** לשונית "נסגרו (90 יום)" עם סינון **לפי לקוח** ו**לפי תקופה** (היום, 7 ימים, 30 יום, החודש, חודש שעבר, 90 יום), וסיכום של כמה משלוחים נמסרו ובכמה כסף. נוח לחשבון של סוף החודש.
- **➕ הוספת הזמנה ידנית** בדף הניהול: מדביקים את הודעת ההזמנה מווצאפ, הפרטים מתמלאים לבד, ושומרים בטבלה. כך מכניסים הזמנה שלא נקלטה. אם מספר ההזמנה זהה להודעה, הלקוח רואה את הסטטוס שלה, והאתר שלו לא ישלח אותה שוב.
- הכניסה לדף הניהול היא עם הסיסמה שמוגדרת ב-`ADMIN_PASSWORD` בקוד של גוגל. מקלידים אותה פעם אחת, והמכשיר זוכר.

### עדכון הקוד בגוגל (אחרי שינוי ב-google-apps-script.gs)
1. ב-Apps Script מוחקים את הקוד הישן ומדביקים את החדש.
2. ב-`ADMIN_PASSWORD` כותבים סיסמה (לפחות 6 תווים) ושומרים.
3. **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy.** הכתובת נשארת אותה כתובת.
